## About

Computer Engineering student building **AI systems that hold up in production** — retrieval pipelines, agent orchestration, and the backends underneath them.

Most of my work lives at the intersection of **applied LLM engineering** and **systems design**: making retrieval accurate and auditable, keeping inference costs at zero where local models suffice, and shipping it behind a clean API.

**Current focus**

| | |
|---|---|
| **Retrieval-Augmented Generation** | Hybrid and vectorless retrieval, reranking, citation tracing |
| **Multi-Agent Systems** | Agent orchestration, hand-off protocols, human-in-the-loop checkpoints |
| **Backend Engineering** | Async FastAPI services, API design, caching, observability |
| **Software Architecture** | Modular boundaries, offline-first design, cost-aware infrastructure |

## Featured Projects

### [Hybrid RAG Chatbot](https://github.com/Ishrat-Bhullar/rag-chatbot-mongodb)

Document-QA system over a PDF corpus using **hybrid retrieval** — dense vector similarity fused with BM25 keyword search — so neither semantic drift nor exact-term queries get dropped. Multilingual embeddings, OCR for scanned pages, table extraction, and a local LLM behind a FastAPI service with both React and Streamlit frontends.

`Python` · `FastAPI` · `ChromaDB` · `FAISS` · `BM25` · `React` · `Ollama` · `Tesseract OCR`

<a href="https://github.com/Ishrat-Bhullar/rag-chatbot-mongodb"><img alt="Repository" src="https://img.shields.io/badge/Repository-0D1117?style=flat-square&logo=github&logoColor=8B949E"></a>

---

### [Autonomous SDLC Platform](https://github.com/Ishrat-Bhullar/sdlc-platform)

Multi-agent platform that turns business requirements into production-ready software artifacts. Specialized agents — requirements analysis, business analyst, solution architect, database design, UI/UX, security architect — collaborate across the lifecycle with **human approval checkpoints** between phases and a memory agent carrying context forward.

`Python` · `TypeScript` · `Multi-Agent Orchestration` · `LLMs` · `FastAPI` · `React`

<a href="https://github.com/Ishrat-Bhullar/sdlc-platform"><img alt="Repository" src="https://img.shields.io/badge/Repository-0D1117?style=flat-square&logo=github&logoColor=8B949E"></a>

---

### [DOCINT — Vectorless RAG](https://github.com/Ishrat-Bhullar/vectorless-chatbot)

Document intelligence platform that removes the vector database entirely: **BM25 lexical retrieval + cross-encoder reranking**, then grounded generation via a local LLM. No embeddings, no cloud calls, no recurring cost — and interpretable retrieval scores instead of opaque cosine similarity. Bilingual (English/Gujarati) OCR and query support, built for offline government and enterprise document workflows.

`Python` · `FastAPI` · `BM25` · `Cross-Encoder Reranking` · `Ollama` · `Streamlit` · `Tesseract OCR`

<a href="https://github.com/Ishrat-Bhullar/vectorless-chatbot"><img alt="Repository" src="https://img.shields.io/badge/Repository-0D1117?style=flat-square&logo=github&logoColor=8B949E"></a>
